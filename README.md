# Quantum Temporal Feedback Eraser

Can an optical receiver restore an unknown qubit after a photon has carried away its phase, if the receiver can interfere nearby times only and send one short classical message?

| Access model | Exact result |
| --- | --- |
| Disjoint coherent windows | A full relative-phase winding across $`K\ge 2`$ windows needs exactly $`K`$ phase labels. |

```math
\varepsilon_{\mathrm{arr}}(M)=\frac{1-\operatorname{sinc}(\pi/M)}{2}.
```

The message arrives at a fixed time. The photon occupies one accessible rail, and the receiver has calibrated local phase control.
