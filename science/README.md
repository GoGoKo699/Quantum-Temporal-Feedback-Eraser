# Scientific account

The conditional photon waveforms store an unknown qubit's phase in system–field correlations. A coherent detector can choose how that phase appears in its measurement outcomes. Restricting the detector to short windows changes which correction labels can serve all outcomes.

The group of phase labels must work across all accessible windows. In the segmented model this is a common convex polygon problem. The polygon viewpoint yields a constructive optimum and identifies the overlap assumption needed for the exact counting law.
